
# Estudo React - Projeto 1

Este repositório contém um projeto de estudo em React, com foco em componentes, estados e manipulação de eventos.

## Descrição

O projeto inclui exemplos práticos de como trabalhar com:
- Renderização de listas dinâmicas.
- Manipulação de estados com `useState`.
- Comunicação entre componentes por meio de props.
- Eventos como cliques de botão.

### Componentes Principais

#### 1. **ListRender**
Este componente demonstra como renderizar uma lista de objetos e manipular o estado para remover itens aleatórios.

- **Funcionalidades**:
  - Renderiza uma lista de usuários.
  - Permite excluir um usuário aleatório ao clicar no botão.

#### 2. **ChangeMessageState**
Este componente permite alterar mensagens exibidas com base em botões clicados.

- **Funcionalidades**:
  - Exibe botões numerados.
  - Cada botão altera a mensagem exibida ao chamar a função `handleMessage` passada como prop.
